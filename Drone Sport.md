# Gates 
## Types of Gates
- Standard gate: used for scoring points
- Multiplier gate: smaller than standard
A number of standard gates are set up in an arena such that there are many path variations leading between them. A multiplier gate is placed in a central location.

# Match
Two teams of three players face off in a match of 5 minutes. The winner is the team which scores the most points by the end. Any drones that crash during a match are out for the remainder of the match.
# Rules
## Standard Gates
Standard gates are "opened" when a drone flies through a "closed" standard gate.
After 3 seconds, the gate closes and points are awarded to the team that opened it according to the number of unique teammate drones that flew through it:

| Number of Drones | Points                     |
| ---------------- | -------------------------- |
| 1                | 4                          |
| 2                | 4 + (4 + 1) = 9            |
| 3                | 4 + (4 + 1) + (4 + 2) = 15 |


If an opponent's drone flies through an "opened" gate, the gate is immediately closed and no points are awarded.
## Multiplier Gate(s)
Multiplier gates are "controlled" by a team by flying through it. "Control" of the gate is not lost based on time, but can be claimed by the opposing team at any time. The next points awarded to the team that "controls" the multiplier gate is doubled. "Control" of the multiplier gate is then neutralized.
# Variation Ideas
## Player Roles
Each player chooses a role before the match. Possible roles:

| Role       | Effect                                                                        |
| ---------- | ----------------------------------------------------------------------------- |
| Denier     | Gains points for denying opponent gate captures                               |
| Starter    | Gates award bonus points for multiple passthroughs when captured by this role |
| Multiplier | Multiplier gate provides higher multiplier when captured by this role         |

## Consecutive Bonus
A team scoring multiple gates consecutively without being denied garners extra bonus points.

## Gate Types
- Long gate: stays open longer
- Set gate: only awards points when all gates in the set are opened, without any being denied
- Repeat gate: can be flown through multiple times by a single drone, counting as multiple
- Dynamic gates: rotate/move
- Activated gates: gate can only be opened periodically (every other 30 seconds)
- Control gate: gate control doesn't close. Awards points when the majority of control gates are controlled by one team.

## Forced Stop
Each drone must go to a rest stop for 10 seconds each match.
